Method and caveats. Energy per query = (latency + output tokens / throughput) × server power × utilization × PUE, estimated from API telemetry (Jegham et al. 2025), snapshot 2026-08-12, standardized at 1,500 output tokens and scaled by task-dependent token counts. Claude Opus 5 has no telemetry row yet; its figure is computed with the same formula from Artificial Analysis speed and latency, calibrated on Claude 4.5 Sonnet (marked est.). Token counts per task and the success proxy are working assumptions. Capability floors use the Artificial Analysis intelligence index plus agentic benchmarks. Inference only: training, embodied hardware, and networking are excluded. Whiskers show ±1 standard deviation. Vendor-disclosed figures (Google: 0.24 Wh per median Gemini prompt; OpenAI: 0.34 Wh per average ChatGPT query) sit roughly 10x lower because they cover shorter prompts and assume high batching: treat levels as indicative and comparisons as the signal. Telemetry also conflates model size with serving speed, which is why Claude 4.5 Haiku scores above Sonnet. Sources: arXiv:2505.09598, HowHungryisAI dashboard, The Climate Brink.
